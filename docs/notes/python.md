# Python 笔记

## 基础语法

### 变量和数据类型

```python
# 基本数据类型
name = "onism99"
age = 20
scores = [95, 87, 92]
is_student = True

print(name, age, scores, is_student)
```

### 字符串操作

```python
s = "Hello Python"
print(s.upper())  # 转大写
print(s.lower())  # 转小写
print(len(s))     # 长度
```

## 函数

```python
def greet(name):
    return f"Hello, {name}!"

print(greet("onism99"))
```

## 列表和字典

```python
# 列表
numbers = [1, 2, 3, 4, 5]
print(numbers[0])  # 访问元素

# 字典
person = {"name": "onism99", "age": 20}
print(person["name"])
```
